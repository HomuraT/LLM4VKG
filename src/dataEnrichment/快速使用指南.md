# 数据增强模块 - 快速使用指南

## 三种方法快速对比

| 方法 | 使用数据源 | 调用方法 | 输出目录 |
|-----|-----------|---------|---------|
| 方法1（原始） | table_info.json + graph.ttl | `process_database()` | `output/{db_name}/` |
| 方法2（新增） | 仅 table_info.json | `process_database_table_only()` | `output/table_only/{db_name}/` |
| 方法3（新增） | 仅 graph.ttl | `process_database_graph_only()` | `output/graph_only/{db_name}/` |

## 快速开始

### 1. 单独使用某一种方法

```python
from src.dataEnrichment.main import DataEnrichment

# 初始化
enricher = DataEnrichment()
db_name = "cmt_denormalized"

# 选择一种方法
output_path = enricher.process_database_table_only(db_name)  # 仅使用table_info
# output_path = enricher.process_database_graph_only(db_name)  # 仅使用graph.ttl
# output_path = enricher.process_database(db_name)              # 使用两者
```

### 2. 运行所有三种方法

```bash
# 方式1：直接运行main.py（会依次执行所有三种方法）
python src/dataEnrichment/main.py

# 方式2：运行示例脚本
python src/dataEnrichment/example_usage.py
```

### 3. 在Python代码中使用

```python
from src.dataEnrichment.main import DataEnrichment

enricher = DataEnrichment()
db_name = "your_database_name"

# 执行所有三种方法
results = {
    'method_1': enricher.process_database(db_name),
    'method_2': enricher.process_database_table_only(db_name),
    'method_3': enricher.process_database_graph_only(db_name)
}

# 查看结果
for method, path in results.items():
    print(f"{method}: {path}")
```

## 输出文件

每种方法都会生成两个文件：

1. **enriched_graph.ttl** - 增强后的TTL图文件（包含新推断的外键关系）
2. **enrichment_analysis.json** - 分析结果的JSON格式文件

## 目录结构示例

```
output/
├── cmt_denormalized/                    # 方法1的输出
│   ├── enriched_graph.ttl
│   └── enrichment_analysis.json
├── table_only/                          # 方法2的输出
│   └── cmt_denormalized/
│       ├── enriched_graph.ttl
│       └── enrichment_analysis.json
└── graph_only/                          # 方法3的输出
    └── cmt_denormalized/
        ├── enriched_graph.ttl
        └── enrichment_analysis.json
```
